# WWALK Lab: SpatialR Workshop
Author: Bella Richmond   

The goal of this workshop is to familiarize the WWALK lab with knowledge regarding packages, basic analyses, and mapping strategies that we can use to clean, analyze, and visualize spatial data within R. 

The slides can be found [here](https://wwalk-lab.github.io/spatialR-workshop/). The workthrough of examples including data, code, and outputs can be found in the `example/` folder.     

Dependencies for this workshop include `sf`, `terra`, `tidyterra`, `dplyr`, `tidyr`, `tibble`, `ggplot2`, `mapview`, `basemaps`, and `osmdata`.
